# Sicherheitsmeldungen

Sende Details zu einer vermuteten Schwachstelle über die private Meldefunktion im GitHub-Tab **Security**, sobald diese für das Repository freigeschaltet ist. [Private Meldung öffnen](https://github.com/erazer90/Localgrammar/security/advisories/new)

Falls die Funktion fehlt, gibt es in diesem Repository derzeit keinen bestätigten privaten Meldeweg. Die Issues sind aktuell deaktiviert. Der Maintainer sollte die private Meldefunktion in den Repository-Einstellungen unter **Security** aktivieren. Veröffentliche keine Schwachstellendetails, Zugangsdaten oder persönlichen Texte in öffentlichen Pull Requests oder Kommentaren.

Für die Analyse helfen die Version der Erweiterung und des Browsers, der betroffene Editor sowie Schritte mit erfundenem Text. Entferne personenbezogene Daten aus Protokollen und Bildschirmfotos.
